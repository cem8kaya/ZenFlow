## 3. App Review notları (Review Notes alanına, İngilizce)

```
No account or login is required. All data stays on the device.

New in 1.1:
• Background audio (UIBackgroundModes = audio): the new Sleep Mode plays the user's chosen ambient sound (rain, ocean, etc.) with the screen dimmed, and the sound must keep playing if the user locks the phone. The audio session is switched to .playback only while Sleep Mode is running and restored afterwards. The sound fades out on its own when the timer ends.
• Zen Coach is an on-device, rule-based breathing and mindfulness assistant (no network, no account). It is not a medical or therapy product. If a message suggests self-harm, it replies with a supportive message and emergency resources (112 / 988 / 116 123, findahelpline.com) and never suggests an exercise instead. A disclaimer is shown on the Zen Coach screen.
• Siri / Shortcuts (App Intents) open the app to a breathing exercise, focus timer, Sleep Mode or the weekly report.
• Backup & Restore (Settings > Back Up & Restore) exports the user's data as a JSON file via the share sheet and imports it with the system file picker.
• The zenflow:// URL scheme is now registered; it is used by Siri, notifications and deep links.

Purchases: one non-consumable "MyZenFlow Premium" (lifetime). "Restore Purchases" is in Settings. Premium unlocks extra breathing exercises and sounds, mood insights chart, custom breathing exercises, custom focus lengths, breathing themes and extra streak freezes.

HealthKit is unchanged: the app only writes Mindful Minutes after a session.

To test Sleep Mode: Zen Coach tab > moon icon > choose a sound and a time > "Fall Asleep" (tap the dark screen to reveal "End").
```
